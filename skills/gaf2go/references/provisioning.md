# GO OBO 参考数据供给

| 项目 | 约定 |
| --- | --- |
| 资源 | Gene Ontology OBO 格式本体（推荐 `go-basic.obo`）。 |
| 目标位置 | `ref/go-basic.obo`。 |
| 获取责任 | 平台管理员从 Gene Ontology 官方发布渠道下载并记录发布日期与版本。 |
| 典型大小 | 数十 MiB，禁止放入技能包。 |
| 校验 | 管理员执行 `sha256sum ref/go-basic.obo`，将校验值记录在本次任务的运行记录中。 |

若该路径不存在，停止执行并请求管理员供给有效本体；不要通过技能脚本联网下载或将本体复制进输出目录。
