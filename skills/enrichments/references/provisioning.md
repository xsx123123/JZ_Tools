# Reference Data Provisioning

| Resource | Typical size | Target location | Administrator action | Validation |
|---|---:|---|---|---|
| GO OBO ontology | 20–40 MiB | `ref/go-basic.obo` | Obtain a versioned GO ontology release from the approved reference-data source and mount it read-only. | Confirm the file starts with `format-version:`. |
| Species gene association | Varies | `ref/gene_association.tsv` | Export the approved species annotation in tabular GO-association form and record its release date with the analysis. | Confirm it has a gene ID column and GO term column used by the selected association parser. |

Use a checksum generated by the platform administrator, for example `sha256sum ref/go-basic.obo ref/gene_association.tsv`, and retain the two hashes in the analysis record. Do not place these resources in the skill package.
