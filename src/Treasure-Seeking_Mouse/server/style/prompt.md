### 【前端重构与视觉体验升级任务指令】

#### 任务目标

将「GEO 寻宝鼠」目前的“偏冷极简管理后台”界面，彻底改造为兼具“高校同门科研搭子温度”**与**“探矿挖宝工坊趣味”的治愈系科研工作台。保持现有后端交互逻辑与 API 完全不变，仅对全局主题色、布局组件、示例卡片、底部输入流与桌宠互动状态进行沉浸式重构。

---

#### 1. 全局设计系统与主题色（Design Tokens）

请在 CSS 根变量或 Tailwind 配置中定义并全局替换现有颜色：

```css
:root {
  /* 背景与卡片色 */
  --bg-page: #FAF8F5;            /* 暖米白主背景，取代原有的冷白 */
  --bg-card: #FFFFFF;            /* 纯白主卡片背景 */
  --bg-card-subtle: #F6F3EE;     /* 便签与次级卡片底色 */
  
  /* 品牌与探矿主题色 */
  --color-gold: #D97706;         /* 探矿金/琥珀色：高亮重点词、金块、hover 焦点 */
  --color-gold-hover: #B45309;
  --color-gold-light: #FEF3C7;   /* 浅金便签底色 */
  --color-miner-green: #15803D;  /* 矿工帽森林墨绿：主行动按钮、状态标签、徽章 */
  --color-miner-green-hover: #166534;
  --color-miner-green-light: #DCFCE7;
  
  /* 文本与边框 */
  --text-main: #292524;          /* 温暖深炭黑（非死黑） */
  --text-muted: #78716C;         /* 温暖次级灰 */
  --border-light: #E7E5E4;       /* 柔和边界线 */
  --shadow-soft: 0 4px 20px -2px rgba(120, 113, 108, 0.08); /* 柔和阴影 */
  --radius-lg: 20px;             /* 统一圆角 */
  --radius-md: 12px;
}

```

* **背景网格**：在 `body` 或顶层容器上增加极微弱的工程图纸浅点阵或 24px 微网格底纹（opacity 控制在 0.03 ~ 0.05 之间），营造摊开藏宝图的质感。

#### 2. 顶部 Hero 区域与文案重构

* **容器重构**：将孤立居中的小头像与干瘪文字，重构为圆润卡片式 Hero 区（最大宽度 780px，居中）。
* **角色与标语排版**：
* **主标语（H1）**：`GEO 寻宝鼠 · 你的同门生信探险搭子`（字体加粗，字号 24px，文字颜色为 `--text-main`，“GEO寻宝”四个字使用 `--color-miner-green`，鼠字或矿脉带上 `--color-gold`）。
* **副标语（Sub-headline）**：`“不查迷宫，只挖宝藏。随口说出课题，阿寻戴上矿工帽这就下铲！”`（字号 14px，颜色 `--text-muted`）。
* **介绍文案**：保留“阿寻的小鼻子可灵了！一头扎进 GEO、SRA、ENA、GSA 数据库里刨拉半天，不仅能嗅出高分数据集、啃透繁杂编号，还能把打包好的样本宝藏一口气叼到你跟前。”将其放入浅米色背景框（`--bg-card-subtle`），内边距 `p-4`，圆角 `--radius-md`。

#### 3. 示例模块升级：从文字列表转为“探矿任务牌（Actionable Pills）”

将现有的 `01 探矿定位`、`02 验宝鉴宝`、`03 清点矿藏` 区域拆解重构成任务看板：

* **模块分组标题规范**：
* `01 探矿定位 ⛏️️` + 胶囊小标签：`[适合：只有一个课题设想时]`（浅绿背景小文字）
* `02 验宝鉴宝 💎` + 胶囊小标签：`[适合：手里只有一串编号时]`（浅琥珀色背景小文字）
* `03 清点矿藏 📜` + 胶囊小标签：`[适合：摸底样本量与平台分布]`


* **问题条目（Prompt 项）组件化**：
* 彻底放弃纯文本排版。每一个示例问题（如“找小鼠脂肪组织的 Bulk RNA-seq 数据集”）改造为独立的微卡片或药丸（Pill）按钮：
* 样式：白底/浅米底，带 1px `--border-light`，内边距 `px-3.5 py-2`，圆角 `8px`。
* 交互（Hover）：鼠标悬停时轻微上浮（`translateY(-2px)`），边框变为 `--color-gold`，背景过渡为微浅黄色（`--color-gold-light`），光标为 `pointer`。
* 点击行为：点击后自动将文本填入底部输入框并聚焦。

---

#### 4. 右下角桌宠（阿寻）交互升级与气泡机制

* **气泡对话框（Speech Bubble）实现**：
* 在阿寻头像/立绘上方渲染一个绝对定位的圆角气泡对话框（带朝下的小三角尖角）。
* 气泡每隔 12 秒在以下语录库中平滑淡入淡出（也可支持用户点击气泡手动切换）：
1. *“师兄师姐催数据了？别慌，告诉我你想挖哪篇！”*
2. *“刚进组看不懂 GSE/GSM 编号？把代号丢给我，阿寻去刨底细！”*
3. *“今天想找小鼠还是人的转录组？阿寻的小铲子已经磨利了~”*
4. *“哪怕只有一个模糊的研究方向，阿寻也能顺藤摸瓜！”*




* **微动效交互**：
* 鼠标 Hover 阿寻立绘时，触发轻微回弹缩放（`transform: scale(1.05)`）或帽子小角度摇晃动效。



---

#### 5. 底部输入栏（The Command Station）

* **Placeholder 引导语替换**：
* 改为：“随口告诉阿寻你想挖什么，比如：‘帮我找找阿尔茨海默病相关的人脑 RNA-seq’…”


* **发送按钮重塑**：
* 按钮主色调整为矿工绿（`--color-miner-green`），Hover 时加深为 `--color-miner-green-hover`。
* 图标及文本：将冷清的纸飞机图标替换为“小铲子图标 ⛏️”或右侧紧跟文本“下铲挖宝”。


* **联动细节**：
* 当用户在输入框键入字符（`input.value.length > 0`）时，给右下角阿寻添加一个带有跃动感的 CSS class，表现出“小跟班竖起耳朵随时准备出发”的呼应感。


* **底部免责小字**：
* 统一保留在输入框下方居中或右下角：`“阿寻挖的宝藏检索自全球公共组学数据库，具体信息请以 NCBI / NGDC 原始条目为准”`（颜色 `--text-muted`，字号 12px）。
